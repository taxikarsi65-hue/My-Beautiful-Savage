# 🗺️ Карта сайта Nuru Nyota — где что лежит и где править

Этот файл — твоя навигация. Держи его открытым, когда мы вносим правки:
достаточно сказать «правим блок 4 → помёт A → щенок Ázík», и мы оба сразу
понимаем, о чём речь.

---

## 📁 Структура файлов

```
index.html          → Úvod (главная)
novinky.html        → Novinky (новости)
nasi-basenji.html   → Naši Basenji (список собак)
pes.html            → карточка одной собаки (открывается по клику из списка)
nas-chov.html       → Náš chov (помёты)
fotogalerie.html    → Fotogalerie
odkazy.html         → Odkazy (ссылки)
kontakty.html       → Kontakty

data.js   ← 📝 ВЕСЬ ТЕКСТ САЙТА. 90% правок — здесь.
app.js    ← вёрстка блоков (как данные превращаются в HTML). Правим редко.
styles.css← цвета, шрифт, отступы. Правим по желанию.
```

> ⚙️ Принцип: **страницы (`.html`) сами по себе почти пустые.** Они берут
> контент из `data.js`. Поэтому чтобы поменять текст — почти всегда идём в `data.js`,
> а не в html.

## ✏️ Частые правки — короткие рецепты

### Поменять название питомника
`data.js` → `SITE.kennel.name`. Оно автоматически подставится в шапку, подвал,
заголовок главной и `<title>` всех страниц.
> Имя в текстах («Nuru Nyota» внутри абзацев про имя, в именах собак типа
> «Amara **Nuru Nyota**») меняется отдельно — это обычный текст в тех же блоках.

### Добавить новость
`data.js` → `SITE.novinky` → скопируй один блок `{ date, title, text, photo }`
и вставь **в самый верх** массива (новые сверху). `photo: true` — показать заглушку фото.

### Добавить собаку
`data.js` → `SITE.dogs` → скопируй блок целиком. Обязательно поменяй `slug`
(уникальный, латиницей, без пробелов) — это адрес карточки. Остальные поля:
Sire/Dam/дата/Fanconi/PRA/зубы/выставки.
Здоровье: пиши `"clear"` или `"carrier"` — цветной бейдж проставится сам.

### Добавить помёт
`data.js` → `SITE.litters` → скопируй блок. Внутри `puppies` — по блоку на щенка
(имя, прозвище, цвет ошейника, время, вес по неделям). Снизу — `parents`.
Вес: строки берутся из ключей `weights` в том порядке, как написаны.

### Заменить фото-заглушки на реальные фото
Сейчас везде стоит рамка «Foto bude doplněno». Когда будут файлы:
- либо скажи мне — переделаю заглушки на настоящие `<img>` с папкой `/fotky/`;
- быстрый вариант для галереи/новостей — та же логика, добавим поле `img: "fotky/xxx.jpg"`.

### Поменять цвет / шрифт
`styles.css` → блок `:root` в самом верху. Меняешь одну переменную (напр. `--accent`)
— меняется весь сайт.

### Вставить карту в контакты
`data.js` → `SITE.kontakty.mapEmbedUrl`. В Google Maps: *Sdílet → Vložit mapu*,
скопируй ссылку из `src="..."` и вставь. Пусто `""` — покажется заглушка.
